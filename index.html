Ch1 – Ch6 核心效能公式與必考黃金定律總表 Master Formula Cheat Sheet
[Ch1] CPU Performance Iron Law：
CPU Time = Instruction Count (IC) × CPI × TCC = (IC × CPI) / (Clock Rate)
[Ch1] CMOS Dynamic Power Wall：
Power ∝ (1) / (2) × Capacitive Load C × Voltage2 × Frequency Switched
[Ch1 & Ch6] Amdahl's Law：
Timproved = (Taffected) / (Improvement Factor) + Tunaffected （100 核達 90× 要求 Fserial ≤ 0.1%）
[Ch2] MIPS Branch vs. Jump Target Addressing：
• Branch (PC-relative)：Target = (PC + 4) + (SignExt(imm16) ≪ 2)
• Jump (Pseudodirect)：Target = (PC+4)[31:28] ‖ (addr26 ≪ 2)
[Ch3] IEEE 754 Floating-Point & Hamming SEC：
• Normalized：(-1)S × (1 + Fraction) × 2(Exp - Bias) (Bias: 127 / 1023)
• Denormalized (Exp=0)：(-1)S × (0.Fraction) × 2-126 (Gradual Underflow 2-149)
[Ch4] Pipeline Speedup & Hazard Conditions：
• EX/MEM Forwarding：EX/MEM.RegWrite && Rd != 0 && Rd == ID/EX.Rs(Rt)
• Load-Use Stall：ID/EX.MemRead && (Rt == IF/ID.Rs || Rt == IF/ID.Rt)
[Ch5] Cache AMAT, Multilevel CPI & Availability：
• AMAT = Hit Time + Miss Rate × Miss Penalty
• Total Bits = 2n × (Block Data Bits + Tag Bits + Valid + Dirty)
• Availability = (MTTF) / (MTTF + MTTR)；Hamming SEC：2p ≥ d + p + 1
[Ch6] Roofline Performance Model & Network Bisection：
• Attainable GFLOP/s = min(Peak Mem BW × AI, Peak FP GFLOP/s)
• Bisection Bandwidth：Ring = 2, 2D Mesh = √(N), Torus = 2√(N), n-Cube = N/2
